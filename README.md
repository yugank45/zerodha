# Zerodha-Clone

A full-stack Zerodha trading platform clone built with React, Node.js, Express, and modern web technologies.

## Features

- **User Authentication:** Secure signup and login functionality.
- **Dashboard & Portfolio:** Track holdings, positions, and live margins.
- **Interactive UI:** Clean dashboard components built for seamless navigation.
- **RESTful API:** Robust backend endpoints handling user data and trade logic.

## Tech Stack

- **Frontend:** React, HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB / Mongoose
